# Staffly media provenance

Logo and social preview are unchanged copies from the Staffly Flutter project’s `store/assets/`. Nine localized app screenshots were converted from that project’s synthetic Play Store phone screenshots to WebP at quality 88. No customer records or stock screenshots were introduced.

Manrope (Latin and Latin Extended) and Noto Sans Arabic (Arabic and Latin) variable WOFF2 fonts were copied from the original project’s Fontsource packages. Their SIL Open Font Licenses are included in `fonts/`. SVG icon geometry was exported once from the original Lucide package; its ISC license is included. No runtime icon package or external font request is required.

`manifest.json` records file sizes and SHA-256 checksums at conversion. The existing favicon is preserved.
